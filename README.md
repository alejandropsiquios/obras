# Obras literarias y textos de Alejandro Psíquios

Sitio web dedicado a la publicación y difusión de obras literarias, textos breves, poesía y relatos de Alejandro Psíquios.

La web reúne una selección de textos originales escritos en español, incluyendo poesía, prosa breve, relatos y diferentes proyectos literarios desarrollados de forma independiente.

## Sobre este proyecto

Este repositorio contiene los archivos de la web literaria personal de Alejandro Psíquios, publicada mediante GitHub Pages.

El sitio funciona como un espacio independiente para descubrir y leer textos literarios, conocer diferentes obras y acceder a sus correspondientes ediciones publicadas.

La propuesta se centra en la literatura como una forma de exploración de la experiencia humana: estados emocionales, relaciones, pérdida, identidad, pensamiento, transformación y las contradicciones de la vida cotidiana.

## Obras y textos

La web reúne diferentes tipos de creación literaria:

* Poesía y micropoesía
* Textos breves
* Prosa poética
* Relatos
* Narrativa
* Series literarias
* Obras publicadas
* Textos disponibles para lectura online

Entre los proyectos publicados se encuentran obras pertenecientes a diferentes etapas y líneas de creación literaria.

## Leer los textos

La web permite acceder directamente a diferentes textos literarios y obras seleccionadas para su lectura online.

Cada obra dispone de su propia página, con información sobre el texto y, cuando corresponde, enlaces a sus ediciones publicadas.

## Obras publicadas

Algunas de las obras presentadas en la web también están disponibles en Amazon en formato digital y/o físico.

La web no sustituye a las ediciones publicadas: sirve como espacio complementario para conocer al autor, descubrir sus textos y acceder a sus obras.

## Literatura en español

Este proyecto está orientado principalmente a lectores interesados en literatura contemporánea en español, poesía, micropoesía, relatos breves, prosa poética y textos de carácter introspectivo.

El objetivo no es ofrecer respuestas ni soluciones al lector, sino presentar textos que puedan ser leídos, interpretados y reconocidos desde diferentes experiencias personales.
